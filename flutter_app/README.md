# Tulpar Line — приложение водителя (Flutter)

Кликабельный прототип по ТЗ v2.0 на Flutter (iOS / Android / Web). Данные демонстрационные, интеграции Yandex и Kaspi не подключены, backend отсутствует — всё состояние в `lib/state.dart`.

## Запуск
```bash
cd flutter_app
flutter pub get
flutter run                 # на подключённом устройстве / эмуляторе
flutter run -d chrome       # в браузере
flutter build apk           # Android
flutter build ios           # iOS (нужен macOS)
```

## Структура
- `lib/state.dart` — состояние и бизнес-правила прототипа (деньги — целые тенге, резервирование заявок, пороги кэшбэка).
- `lib/ui.dart` — общие виджеты и стиль (карточки, чипы, графики, логотип, иллюстрации).
- `lib/screens/` — Главная, Финансы, Сервис, Профиль, Депозит-карта, Рейтинг и остальные экраны.

## Важно
- Нижнее меню: «Главная», «Финансы», «Сервис», «Профиль». Coins и Coins Market отсутствуют.
- Параметры лояльности (порог, ставка, расчётная база, окно вывода) предварительные; их утверждает владелец.
- Демо-инструменты: «Профиль → Демо-инструменты».
